## 一、个人信息与画像

### 1.1 个人定位设置

**功能说明**：让 AI 记住您的身份、业务和目标客户，后续所有智能体都会基于您的定位生成个性化内容。

**解决问题**：
- 每次使用智能体都要重复输入身份信息
- 生成的内容与业务不匹配
- AI 不了解您的专业领域

**操作步骤**：

1. 进入「个人定位设置」页面
2. 填写三个核心问题：
   - **我是谁**：您的身份、职业、专业领域
   - **我卖什么**：您的产品/服务是什么，核心卖点
   - **我卖给谁**：目标客户是谁，他们的痛点和需求
3. 点击「保存定位」

**示例填写**：
```
我是谁：财税顾问，10年企业税务筹划经验，服务过500+中小企业
我卖什么：企业税务筹划服务，帮企业合法节税30%-50%，提高利润
我卖给谁：年营收500万以上的中小企业老板，税负过重，想合法节税
```

**注意事项**：
- 信息越详细，AI 生成的内容越精准
- 可随时修改，支持多个定位配置

## 二、强人设IP-构建知识库

### 2.1 知识库构建

**功能说明**：上传您的专业资料、案例、文章，让 AI 学习您的知识体系。

**解决问题**：
- 生成的内容不够专业
- AI 不了解您的业务细节
- 需要反复解释业务背景

**操作步骤**：

1. 进入「知识库构建」页面
2. 上传您的专业资料：
   - Word 文档（产品介绍、案例资料等）
   - PDF 文件（行业报告、白皮书等）
   - 网页链接（您的公众号文章、官网等）
3. 等待 AI 处理完成
4. 后续使用其他智能体时，可选择调用知识库

### 3.1 强人设爆款选题

**功能说明**：基于您的个人定位，自动生成 10 个适合您人设的爆款选题。

**解决问题**：

## 四、信任流量-公域精准获客

### 4.1 小红书图文获客

**功能说明**：一键生成 10 个爆款选题，可编辑后生成完整的图文内容（包含封面图和正文）。

**解决问题**：
- 不知道在小红书发什么
- 选题不够吸引人
- 不会设计封面图
- 文案不够吸引客户

**操作步骤**：

1. 进入「小红书图文获客」页面
2. 选择您的个人定位
3. 点击「生成选题」
4. 从 10 个选题中选择一个，点击「生成图文」
5. 等待生成完成（包含封面图 + 正文 + 标签）
6. 点击图片可下载，正文可复制
7. 点击「上次选题」可查看历史记录

**输出内容**：
- ✅ 1 张封面图（可下载）
- ✅ 完整正文内容
- ✅ 推荐标签
- ✅ 爆款标题建议

**注意事项**：
- 选题可编辑修改后再生成图文
- 图片支持右键另存为或点击下载按钮
- 每次生成会避免与上次选题重复

### 4.2 AI 口播视频生成器

**功能说明**：上传图片，AI 自动生成口播文案和营销视频。

**解决问题**：
- 不会写口播文案
- 视频制作成本高
- 不知道如何用视频获客

**操作步骤**：

1. 进入「AI 口播视频生成器」页面
2. 上传首帧照片（视频开始画面）
3. 可选：上传尾帧照片（视频结束画面）
4. 点击「一键生成」自动生成两段文案（每段 62-72 字）
5. 编辑文案（可修改）
6. 点击「开始生成视频」
7. 等待视频生成完成（约 2-5 分钟）
8. 点击「下载视频」保存

**输出内容**：
- ✅ 两段口播文案（可编辑）
- ✅ AI 生成的营销视频（可下载）

**注意事项**：
- 视频生成需要 2-5 分钟，高峰期可能更长
- 上传的图片会自动保存，下次打开页面会显示
- 可配置自己的火山引擎 API，用自己的 API 不扣积分

**配置自己的 API（可选）**：
1. 登录火山引擎控制台
2. 开通「视觉模型」服务
3. 创建推理接入点，选择 Doubao-Seedance 模型
4. 复制接入点 ID 和 API Key
5. 在页面下方填写配置并保存

## 六、信任兑现-销售高效成交

### 6.1 AI 复制销冠智能体

**功能说明**：上传销冠案例资料，AI 帮您分析并生成销售成交话术指导。

**解决问题**：
- 新销售不会谈客户
- 销售话术不够专业
- 成交率低，不知道哪里出了问题
- 想学习销冠的经验

**操作步骤**：

1. 进入「AI 复制销冠智能体」页面
2. 上传 4 份资料：
   - **参考销冠聊天记录**：优秀销售的聊天记录（Word 文档）
   - **产品信息**：您的产品/服务介绍
   - **客户信息**：目标客户画像和背景
   - **我与客户最近对话**：您与客户的沟通记录
3. 可选：上传客户朋友圈截图（AI 会分析客户状态）
4. 点击「开始分析」
5. 等待 AI 分析完成
6. 获得详细的销售话术指导

**演示案例**：
- 点击「演示案例」可使用预设的演示资料体验功能
- 每个演示文件可下载作为模板参考

**输出内容**：
- ✅ 客户需求分析
- ✅ 销售策略建议
- ✅ 具体话术指导
- ✅ 下一步行动建议

**注意事项**：
- Word 文档内容越详细，分析结果越精准
- 朋友圈截图可帮助 AI 更好理解客户状态
- 支持多轮对话，可持续获取建议

## 常见问题解答

### Q1：积分是怎么计算的？

- 1 积分 = 0.01 元
- 会员赠送 650 积分 = 6.5 元价值
- 积分消耗基于真实 API 成本，有 30% 溢价

### Q2：用自己的 API 会扣积分吗？

如果您在智能体中配置了自己的 API 密钥（如火山引擎视频生成 API），使用自己的 API 不会扣除平台积分。

### Q3：图片/视频无法下载怎么办？

1. 尝试右键「另存为」
2. 刷新页面后重新生成
3. 检查浏览器是否阻止了下载

### Q4：生成失败怎么办？

1. 检查网络连接
2. 刷新页面重试
3. 检查是否登录状态
4. 如持续失败，联系客服

### Q5：如何保存生成的内容？

- 图片：点击图片或下载按钮保存
- 文字：复制文本内容
- 视频：点击下载按钮保存
- 所有生成记录会保存在账户中
