## 一、数据诊断（先看数据，再定动作）

你提供的月均数据如下：

| 环节 | 月均数量 | 环节转化率 |
|------|----------|------------|
| 咨询/询盘 | 100 条 | — |
| 有效报价 | 30 条 | 30%（咨询→报价） |
| 成交 | 8 单 | 26.7%（报价→成交） |
| 回款周期 | 30~60 天 | — |

### 1. 当前数据观察

- **咨询→报价流失 70%**：100 条咨询只有 30 条能进入有效报价，说明大量咨询在"了解阶段"就停住了——要么客户只是随口问价，要么销售没有把咨询推进到需求诊断和方案呈现。
- **报价→成交仅 26.7%**：30 条报价只成交 8 单，接近四分之三的报价石沉大海。这是最大的转化断层。
- **回款周期 30~60 天偏长**：成交后到回款之间缺少明确的付款节点管理和催收节奏。

### 2. 关键断点

| 断点位置 | 表现 | 严重程度 |
|----------|------|----------|
| 断点 A：咨询→有效报价 | 70% 的咨询没有转化为有效报价 | ★★★★ |
| 断点 B：报价→成交 | 73% 的报价没有成交 | ★★★★★（最大断点） |
| 断点 C：成交→回款 | 回款周期不可控，缺少催收节点 | ★★★ |

### 3. 可能原因

**断点 A（咨询→报价流失 70%）的可能原因：**
- 首次接触时没有做需求诊断，客户问价就直接报价，报价后客户拿去比价，销售失去主动权；
- 咨询响应不及时，客户同时问了好几家，谁先给出专业方案谁占先机；
- 销售没有区分"真询盘"和"随口问"，把大量时间花在低质量咨询上，高质量咨询反而跟进不够。

**断点 B（报价→成交仅 26.7%）的可能原因：**
- 报价后缺少结构化的跟进节奏，销售"报完就等"，客户"看完就忘"；
- 报价单只给了价格，没有给出"为什么选我们"的差异化理由（灵活、规范、响应快）；
- 客户决策链上有老板、HR、财务多方，销售只对接了一个人，没有推动内部决策；
- 缺少信任建立动作（案例、资质展示、服务承诺），客户不敢把社保薪酬这种敏感事务交给十几人的小公司；
- 没有设置报价有效期和行动推动节点，客户"再看看"就无限期拖延。

**断点 C（回款周期偏长）的可能原因：**
- 合同里付款节点不清晰，或者执行时没有按节点催收；
- 交付启动和付款没有绑定，客户先用服务后付款，回款自然拖后。

### 4. 优先优化方向

1. **第一优先：报价→成交段（断点 B）** ——这是当前损失最大的环节，30 条报价只成交 8 单，每提升 10 个百分点就是 3 单增量。核心要做的是：报价前先做需求诊断、报价后建立 48 小时/7 天/14 天三级跟进节奏、报价单附差异化理由和信任材料。
2. **第二优先：咨询→报价段（断点 A）** ——核心是做首次接触的需求诊断，把"问价"转化为"诊断需求后再报价"，同时区分真询盘和低质量咨询，把精力集中在高质量线索上。
3. **第三优先：成交→回款段（断点 C）** ——核心是把付款节点写进合同、交付启动绑定首付款、建立到期前提醒和逾期催收节奏。

**后续建议补充的关键数据：**
- 每条咨询的来源渠道（电话/微信/到店/转介绍），判断哪个渠道质量最高；
- 报价后客户未成交的原因标签（价格/资质/决策拖延/选了别家/需求消失）；
- 从咨询到报价的平均响应时长；
- 成交客户的决策周期（从首次接触到签约的平均天数）；
- 回款逾期比例和平均逾期天数。

## 四、核心动作（精简为 5 个）

### 动作 1：首次接触 & 需求诊断

| 项目 | 内容 |
|------|------|
| **动作名称** | 咨询后 5 分钟内首触达 + 需求诊断 |
| **目标** | 在客户问价时先不报价，先做需求诊断，把"随口问价"转化为"有效需求"，并拿到决策人信息 |
| **触发时间** | 客户发起咨询后 5 分钟内（工作时间）；非工作时间则次日 9:00 前 |
| **具体行为** | ① 5 分钟内电话或微信回复，自报身份和来意；② 用 3 个诊断问题了解客户：企业人数和当前社保/薪酬处理方式、当前最头疼的 HR 问题、决策人是谁；③ 记录客户需求标签（人数规模、服务类型、痛点、决策人、紧急程度）；④ 告知下一步：会根据需求出一份定制方案，约定下次沟通时间 |
| **标准产出** | 客户需求标签表填写完整（至少包含：人数、服务类型、痛点、决策人、下一步时间），并录入 CRM/客户台账 |
| **利他钩子** | 先帮你判断适合哪种方案、大概什么价位，避免你后面来回对比浪费时间 |
| **兴趣点** | "你们现在社保和发薪是谁在弄？有没有出过错或者被员工问住过？"——直接戳中痛点 |
| **信任点** | "我是负责你这块业务的顾问，做了快十年 HR 外包，先帮你把需求理清楚，不合适我也会直说" |
| **行动指令** | "你先花 1 分钟告诉我这三个信息：公司大概多少人、现在社保是自己交还是找机构、最头疼的是哪块？我帮你判断哪种方案最划算" |
| **标准话术** | "王总您好，我是XX人力的小李，刚看到您咨询社保代缴的事。先不急着报价，我想先帮您判断一下哪种方案最适合你们——您公司现在大概多少人？社保和发薪现在是行政在弄还是找的机构？平时最头疼的是出错还是流程太繁琐？您把这几个告诉我，我今天内给您出一份针对性的方案和报价，避免您拿一个通用价格去对比，反而看不准。" |
| **成功标志** | 拿到 3 个诊断信息 + 决策人 + 约定下次沟通时间 |
| **注意事项** | ① 客户主动问价时，不要直接报数字，先说"价格跟人数和服务类型有关，我先了解一下你的情况，给你一个准的"；② 如果客户坚持要价格区间，给一个区间 + 说明影响因素，然后继续诊断；③ 全程记录，不要凭记忆 |


### 动作 2：方案呈现 & 报价

| 项目 | 内容 |
|------|------|
| **动作名称** | 基于诊断的定制化方案 + 报价单发送 |
| **目标** | 让客户看到"你懂我的情况"，报价单不只是价格，而是解决方案 |
| **触发时间** | 需求诊断完成后 24 小时内（越快越好，最好当天） |
| **具体行为** | ① 根据诊断信息制作一页式方案：客户当前痛点 → 我们怎么解决 → 服务内容清单 → 报价 → 服务承诺；② 报价单附上 2~3 个差异化理由（比大机构灵活、比小作坊规范、响应时效承诺）；③ 附 1 个同规模客户的案例或客户评价（脱敏）；④ 微信发送后电话告知，约定 48 小时内沟通反馈 |
| **标准产出** | 方案报价单发送记录 + 客户已读/已收确认 + 下次沟通时间约定 |
| **利他钩子** | 这份方案是按你的实际情况做的，你看完就知道哪些钱该花、哪些可以省 |
| **兴趣点** | "我按你们 80 人的规模算了一下，如果现在行政自己弄，隐性成本其实比外包还高，我给你列了个对比" |
| **信任点** | "报价里每一项服务内容都写清楚了，没有隐藏收费；我们服务承诺写进合同，出错我们担" |
| **行动指令** | "方案我发你了，你花 3 分钟看一下第三页的服务清单和报价，看完回复我'看了'，我明天上午给你打个电话过一遍，有问题当场解答" |
| **标准话术** | "王总，方案和报价我发你了。这份是按你昨天说的 80 人、社保+发薪一起做来定的，里面把服务内容、报价、我们的响应承诺都写清楚了。你重点看第三页的服务清单，看看有没有漏掉你需要的。看完回复我一下，我明天上午 10 点给你打电话过一遍，你有问题当场问，比你自己琢磨快。" |
| **成功标志** | 客户确认收到方案 + 约定下次沟通时间 |
| **注意事项** | ① 报价单必须包含服务内容清单，不能只给一个总价；② 报价单设置有效期（如 15 天），制造合理紧迫感；③ 案例要选同规模、同行业的，增强代入感 |


### 动作 3：信任建立 & 异议处理

| 项目 | 内容 |
|------|------|
| **动作名称** | 报价后 48 小时跟进 + 异议处理 + 推动内部决策 |
| **目标** | 在客户比价和犹豫的阶段，用信任材料和异议处理把客户拉回来，并推动客户内部决策 |
| **触发时间** | 报价发送后 48 小时内第一次跟进；之后第 7 天第二次；第 14 天第三次 |
| **具体行为** | ① 48 小时内电话跟进，问"方案看了吗？哪里不清楚？"；② 针对客户异议（价格贵/资质担心/再对比对比）用预设话术处理；③ 了解客户内部决策流程（谁拍板、还要给谁看），主动提出"我可以帮你给老板/财务做个 15 分钟说明"；④ 发送信任材料：营业执照、人力资源服务许可证、同规模客户案例、服务承诺书；⑤ 第 7 天和第 14 天分别用不同角度跟进（案例角度、风险角度、服务承诺角度） |
| **标准产出** | 客户异议记录 + 决策链信息 + 下一步明确动作和时间 |
| **利他钩子** | 帮你把方案给老板/财务讲清楚，省得你自己转述漏掉重点；也帮你避坑——有些低价机构后面加价或服务跟不上 |
| **兴趣点** | "上周有个跟你们差不多大的公司，之前自己弄社保漏缴了一个人，补缴加滞纳金花了小一万，我跟你说是想让你注意这个风险" |
| **信任点** | "我们的资质和服务承诺都可以发你看，合同里写清楚出错我们担；你也可以问我们现有客户的反馈" |
| **行动指令** | "你这边还有谁需要一起看方案？要不我明天下午花 15 分钟给你和财务一起过一遍，把该问的一次问清楚，省得你来回转述" |
| **标准话术（价格异议）** | "王总，价格这块我理解你要对比。不过你可以算一下：现在行政每月花在社保发薪上的时间大概多少？出错一次补缴加滞纳金多少？我们的报价里含了出错兜底和响应时效，这部分其实是帮你省风险成本。你要对比的话，建议把服务内容和出错责任一起对比，不然光看价格容易选到后面加价的。" |
| **标准话术（再对比对比）** | "应该的，这事确实要对比。我建议你对比的时候重点看三个：一是资质全不全，二是出错谁担责，三是响应时效写没写进合同。这三个比价格更能决定后面省不省心。你对比完如果还有疑问，随时找我，我帮你一起看。" |
| **成功标志** | 客户明确下一步动作（约演示/给决策人看/确认签约时间）或给出明确异议 |
| **注意事项** | ① 每次跟进必须有新信息或新角度，不要只是"问考虑得怎么样"；② 第 14 天仍无进展的，转入常规维护 SOP，不再高频跟进；③ 异议处理话术要提前培训，让每个销售都能背下来 |


### 动作 4：成交签约 & 首付款确认

| 项目 | 内容 |
|------|------|
| **动作名称** | 合同签署 + 首付款到账确认 |
| **目标** | 把口头意向转化为签约和首付款到账，明确付款节点 |
| **触发时间** | 客户确认意向后 24 小时内发送合同；签约后 7 天内确认首付款到账 |
| **具体行为** | ① 发送标准合同 + 服务确认单，合同中明确付款节点（首付款比例、后续付款时间）；② 电话或当面过一遍合同关键条款（服务内容、付款节点、出错责任、服务期限）；③ 确认首付款金额和到账时间，提供对公账户和付款方式；④ 首付款到账后当天确认并启动交付流程；⑤ 如 7 天内未到账，进入回款催收 SOP |
| **标准产出** | 合同签署完成 + 首付款到账截图/银行记录 + 交付启动通知 |
| **利他钩子** | 早签约早启动，你这个月社保下个月就能交接过来，避免断缴；首付款到账我们当天就开始做交接准备 |
| **兴趣点** | "合同里付款节点我帮你排好了，首付款之后按月付，不用一次压太多现金" |
| **信任点** | "合同里服务内容、出错责任、响应时效都写清楚了，你签之前可以逐条看，有不清楚的我逐条解释" |
| **行动指令** | "合同我发你了，你重点看第二页的服务内容和第四页的付款节点，没问题的话这周签了，我安排下周开始交接，这样下个月社保不会断" |
| **标准话术** | "王总，合同我发你了。付款节点我按你说的排的：首付款 50%，服务启动后 30 天付尾款，这样你现金流压力小一点。你重点看第二页服务清单和第四页付款节点，没问题这周签，我这边安排下周一启动交接，确保下个月社保不断缴。有要改的地方你直接说，我当天改。" |
| **成功标志** | 合同签署 + 首付款到账 |
| **注意事项** | ① 付款节点必须写进合同，不能口头约定；② 首付款到账前不启动正式交付（可以做准备工作，但不承诺服务已开始）；③ 合同关键条款要电话过一遍，不能只发文件 |


### 动作 5：交付启动 & 服务交接

| 项目 | 内容 |
|------|------|
| **动作名称** | 首付款到账后 3 个工作日内完成交付启动 |
| **目标** | 让客户感受到"签约后马上有人管"，建立交付初期的信任，避免"签完就冷落" |
| **触发时间** | 首付款到账后 3 个工作日内 |
| **具体行为** | ① 交付专员 24 小时内联系客户，自报身份和职责；② 发送资料清单（员工名单、社保账号信息、薪酬结构等），约定交接时间；③ 完成系统开户/账号对接；④ 发送服务启动确认函（服务内容、对接人、响应时效、紧急联系方式）；⑤ 启动后第 3 天回访确认交接顺利 |
| **标准产出** | 资料收集完成 + 系统开户完成 + 服务启动确认函发送 + 第 3 天回访记录 |
| **利他钩子** | 资料早交早交接，这个月就能正常走，不会出现断缴或发薪延误 |
| **兴趣点** | "交接清单我整理好了，你按清单准备，大概半小时就能弄完，不用你额外花时间琢磨" |
| **信任点** | "我是负责你后续服务的交付专员，以后社保、发薪、员工问题都找我，响应时效写在确认函里" |
| **行动指令** | "这份资料清单你收一下，按上面列的准备好，我们约周三上午交接，大概 40 分钟，交接完这个月就能正常走" |
| **标准话术** | "王总您好，我是负责您这边后续服务的交付专员小张，首付款已经确认到账了。接下来交接由我跟进，我发你一份资料清单，你按清单准备就行，大概半小时。我们约周三上午 10 点交接，交接完这个月社保就能正常走，不会断。交接后有任何问题直接找我，响应时效我写在确认函里了。" |
| **成功标志** | 资料交接完成 + 系统开户完成 + 客户确认服务已启动 |
| **注意事项** | ① 交付专员必须在首付款到账后 24 小时内联系客户，不能拖；② 资料清单要简单明了，不要让客户觉得麻烦；③ 第 3 天回访是建立信任的关键动作，不能省 |


## 五、流失兜底策略

### 流失点 A：咨询后未接通/未响应

| 项目 | 内容 |
|------|------|
| **流失点** | 客户发起咨询后，销售首次触达未接通或客户未回复 |
| **用户表现** | 电话不接、微信不回、留言未读 |
| **判断标准** | 首次触达后 24 小时内无任何回复 |
| **可能原因** | 客户同时在问多家、暂时忙、只是随手咨询、号码错误 |
| **兜底动作** | 第 1 天换时间段再打一次 + 发一条微信（含利他信息）；第 3 天再发一条案例/风险提醒类微信；第 7 天最后一条，告知"先不打扰，有需要随时找我"，转入常规维护 |
| **兜底话术** | "王总，昨天给您留言可能没看到。我这边刚好整理了一份《中小企业社保常见 5 个坑》，不少老板看完发现自己在踩，我发您参考一下，不涉及推销，您先看看。" |
| **后续归类** | 7 天无回复 → 转入常规维护 SOP（每月 1 次低频触达，发行业提醒/政策变化） |

### 流失点 B：报价后未回复

| 项目 | 内容 |
|------|------|
| **流失点** | 方案报价发送后客户不回复 |
| **用户表现** | 微信已读不回、电话不接、说"再看看" |
| **判断标准** | 报价发送后 48 小时内无实质反馈 |
| **可能原因** | 在比价、方案没看懂、决策人没看到、价格超预算、暂时不紧急 |
| **兜底动作** | 48 小时电话跟进（问具体疑问）；第 7 天换角度跟进（案例/风险提醒）；第 14 天最后跟进（告知报价有效期），之后转入常规维护 |
| **兜底话术** | "王总，方案发了一周了，不知道你那边对比得怎么样。我不催你决定，就是想问一下有没有哪里我没讲清楚，或者你对比下来有拿不准的地方，我帮你一起看看，免得你选错后面麻烦。" |
| **后续归类** | 14 天无进展 → 转入常规维护 SOP（每 2 周 1 次，发政策变化/案例/节日问候） |

### 流失点 C：价格异议未处理

| 项目 | 内容 |
|------|------|
| **流失点** | 客户明确表示"贵了""别家更便宜" |
| **用户表现** | 直接说价格高、拿别家报价对比、要求降价 |
| **判断标准** | 客户明确表达价格异议且未进入下一步 |
| **可能原因** | 只对比了价格没对比服务内容、预算确实有限、用别家报价压价 |
| **兜底动作** | 不直接降价，先做价值对比（服务内容、出错责任、响应时效）；如客户预算确实有限，提供简化版方案（减少服务项）；如仍不接受，转入常规维护 |
| **兜底话术** | "王总，价格我理解。不过建议你对比的时候把三样东西放一起看：服务内容清单、出错谁担责、响应时效。有些报价低是因为后面加价或者出错不管，真出一次事补缴加滞纳金就回来了。你要是预算有压力，我可以帮你调整一下服务组合，把非核心的先去掉，你看行不行？" |
| **后续归类** | 价格谈不拢 → 转入常规维护 SOP（季度触达，政策变化时联系） |

### 流失点 D：决策拖延

| 项目 | 内容 |
|------|------|
| **流失点** | 客户认可方案但迟迟不签约 |
| **用户表现** | 说"再想想""等下个月""要跟合伙人商量" |
| **判断标准** | 报价后 14 天仍无明确签约时间 |
| **可能原因** | 决策人没参与、内部有分歧、当前不紧急、在等别家 |
| **兜底动作** | 主动提出给决策人做 15 分钟说明；帮客户梳理"现在签 vs 再等等"的利弊（断缴风险、政策变化）；设定合理紧迫感（报价有效期、服务排期） |
| **兜底话术** | "王总，方案你认可的话，我建议这个月定下来。一是报价有效期到这个月底，二是下个月社保基数可能调整，早交接早按老基数走。你要是还要跟合伙人商量，要不我花 15 分钟跟他电话过一遍，把该问的一次问清楚，省得你转述。" |
| **后续归类** | 超过 30 天仍拖延 → 转入常规维护 SOP（每月 1 次，政策节点重点触达） |

### 流失点 E：签约后首付款未到账

| 项目 | 内容 |
|------|------|
| **流失点** | 合同签署后首付款未在约定时间内到账 |
| **用户表现** | 签约后拖延付款、说"走流程"、财务不在 |
| **判断标准** | 合同约定付款日后 3 个工作日仍未到账 |
| **可能原因** | 客户内部付款流程慢、财务不在、客户想先用服务后付款 |
| **兜底动作** | 付款日前 1 天提醒；到期未付第 1 天电话确认；第 3 天联系决策人；第 7 天发正式催款函并暂停交付启动 |
| **兜底话术** | "王总，合同约定的首付款今天是付款日，我这边还没看到到账。想确认一下是财务流程还没走完，还是有什么问题？我这边交付准备都做好了，首付款一到账当天就启动交接，避免耽误你这个月社保。" |
| **后续归类** | 超过 15 天未到账 → 销售主管介入，评估是否暂停交付或调整合同 |

## 七、减法建议

### 建议保留的动作（5 个核心动作）

1. **首次接触 & 需求诊断**——解决"咨询→报价流失 70%"的断点，把问价转化为有效需求
2. **方案呈现 & 报价**——让报价单成为解决方案而非价格单，提升报价的专业度和差异化
3. **信任建立 & 异议处理**——解决"报价→成交仅 26.7%"的最大断点，用三级跟进和异议话术推动成交
4. **成交签约 & 首付款确认**——把口头意向转化为合同和首付款，绑定付款节点
5. **交付启动 & 服务交接**——建立交付初期信任，避免"签完就冷落"，为续费和转介绍打基础

### 建议合并的动作
