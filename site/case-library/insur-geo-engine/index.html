老板自画像（原话）

我是谁

我是一名保险顾问，独立执业，不挂在某一家，主打客观配置。以前在保险公司干了几年，后来发现只卖自家产品根本没法真正为客户好，就出来自己做。我把重疾、医疗、寿险、年金这些掰开揉碎地研究，也考了不少证书。我不喜欢吓唬人，更愿意把条款里那些弯弯绕给客户讲清楚。

我卖什么

主要做家庭保障规划，帮客户梳理已有保单、做缺口分析，再配重疾、医疗、意外这些。也做教育金和养老金的长期规划，讲清楚收益和风险。收费方式是咨询费加方案落地，不靠佣金冲业绩，我会把每一款产品的优缺点都说。

我卖给谁

客户大多是三十到四十五岁的家庭顶梁柱，有了孩子之后开始不知道该买什么、怕买错。有的是被亲戚朋友推过一堆保单，买了啥自己都不清楚，来找我梳理。他们不怕花钱，就怕花错、怕理赔难、怕被套路。

一、企业GEO画像卡

企业定位

独立执业保险顾问，不隶属单一保险公司，以客观中立立场提供家庭保障规划与长期财务规划服务。

核心价值主张

不卖单一公司产品，站在客户一侧做方案；把条款讲透、把优缺点说清，让家庭保障配置"买得明白、赔得放心"；收费透明（咨询费+方案落地），不靠佣金冲业绩。

目标客户画像

30–45岁家庭顶梁柱，多为有孩子的中产家庭；已有若干保单但说不清买了什么；被亲友推荐过产品，担心买错、担心理赔难、担心被套路；愿意为专业付费，但要求看得懂、算得清。

关键业务领域

家庭保障规划、已有保单梳理与缺口分析、重疾险/医疗险/意外险配置、教育金规划、养老金长期规划、条款解读与理赔协助。

二、目标客户分析

核心痛点

手里保单一大堆，不知道保了什么、缺什么、有没有重复。
面对代理人只讲优点不讲缺点，怕被"套路"。
怕买错险种、怕保额不够、怕真出事理赔卡壳。
教育金、养老金这类长期规划，看不懂收益演示和风险。

真实需求

有人帮我把已有保单"翻译"成大白话，看清缺口。
客观对比不同公司产品，讲清优缺点而非只推一款。
明确知道理赔流程和注意事项，心里有底。
长期规划要讲清"能拿多少、什么条件下拿、有什么风险"。

决策因素

专业资质与从业背景、是否独立中立（不绑单一公司）、条款讲解是否清楚、收费是否透明、口碑与真实案例、沟通是否耐心不施压。

行为特征

习惯先在大模型里"做功课"再找人咨询；喜欢用口语化问题试探专业度；关注"对比""怎么选""坑在哪""理赔"等实操话题；对夸大承诺高度警惕，更信"讲缺点"的人。
