## ① 人设定位与差异化标签

### 一句话人设定位
> **"被瑜伽救回来的舞蹈生，用12年教龄和一双会调身体的手，专治都市女性的腰、肩、颈和焦虑。"**

### 核心人设三要素
| 维度 | 内容 |
|---|---|
| **身份** | 12年瑜伽老师、4年工作室主理人、教培导师（学员已开馆） |
| **来路** | 舞蹈出身 → 腰伤 → 被瑜伽救回 → 较真教学 |
| **态度** | 宁可慢，不让学员练出伤；不卖年卡，先体验再决定 |

### 差异化标签（记忆锚点）
1. **"被瑜伽救回来的人"** —— 有故事、有共情，区别于科班速成老师
2. **"会用手调身体的老师"** —— 上手纠正、讲清肌肉与呼吸，区别于只喊口令的流水线老师
3. **"较真老师"** —— 动作变形必停，宁慢不伤，建立专业信任
4. **"小班6人上限"** —— 看得见每个人，反大课流水线
5. **"不卖年卡"** —— 反冲动消费，先体验后决定，立"真诚不推销"人设

### 人设关键词云
`舞蹈底子` `腰伤亲历者` `较真` `上手调整` `小班6人` `不卖年卡` `一辈子的事` `备课型老师`


## ② 账号内容定位

### 账号定位一句话
> **一个较真瑜伽老师的"身体修复课堂 + 教学现场"**——既教你怎么练对，也让你看见一个老师是怎么认真对待每个身体的。

### 内容三大支柱
| 支柱 | 占比 | 说明 |
|---|---|---|
| **专业干货（教对动作）** | 50% | 腰肩颈问题纠正、呼吸配合、肌肉讲解、体态自测 |
| **人设故事（我是谁）** | 25% | 舞蹈腰伤经历、较真教学现场、学员变化故事 |
| **观点态度（反常识）** | 25% | 反流水线大课、反年卡、反"练出伤"、反打卡式瑜伽 |

### 目标受众画像
- 25–45岁女性为主
- 久坐白领 / 产后宝妈 / 高压想静下来的人
- 心态：从"试试能不能瘦"到"想解决身体问题、找平静"
- 痛点：腰酸、肩颈紧、睡不好、情绪紧绷、怕练错受伤、反感被推销

### 内容调性
亲切、专业、耐心；说人话不讲玄学；有温度但不煽情；较真但不严厉。


## ③ 核心价值主张

### 主价值主张（对外一句话）
> **"我不教你摆姿势拍照，我教你把身体练对、练不伤。"**

## ⑥ 内容发布节奏与运营动作

### 发布节奏（建议）
| 频率 | 内容类型 | 说明 |
|---|---|---|
| **每周3–4条** | 干货 : 人设 : 观点 ≈ 5:3:2 | 稳定输出，专业打底 |
| **每周1条** | 学员变化 / 教学现场 | 真实感、信任转化 |
| **每月1条** | 来时路 / 深度故事 | 强化人设记忆点 |

### 单条结构节奏
钩子（前3秒痛点/反常识）→ 讲解/故事（15–40秒）→ 上手示范或画面佐证 → 口头禅强化 → 软引导（评论/体验课）

### 运营动作清单
1. **评论区运营**：每条视频固定回复"你哪里最紧"，收集痛点做下期选题
2. **私信承接**：咨询统一引导"先约体验课"，不硬推年卡（呼应人设）
3. **选题库滚动**：把评论区高频问题沉淀成选题表，每周补2条
4. **人设一致性**：所有视频保留"较真/上手/小班/不卖年卡"至少一个标签
5. **转化路径**：短视频 → 体验课 → 小班/私教/教培，分层承接
6. **数据复盘**：每周看3秒完播率与评论互动，保留高效钩子模板


## ⑦ 可复制的爆款内容结构（万能模板）

### 模板A：痛点纠正型（干货主力）
```
【钩子 0–3s】"如果你____（痛点场景），先别____，你可能练反了。"
【共情 3–8s】"我带过太多这样的学员，一进来就说____。"
【拆解 8–30s】"问题在这——（讲肌肉/呼吸/动作），你看这里变形了。"
【上手示范 30–45s】"我会这样把手搭上去，帮她调回来。"
【口头禅 45–50s】"练对，比练多重要。"
【引导 50–55s】"你哪里最紧？评论区告诉我。"
```

### 模板B：故事人设型（信任建立）
```
【钩子】"我是被瑜伽救回来的人。"
【冲突】"腰伤那年，我是跳舞的，以为自己再也动不了。"
【转折】"是瑜伽一点点把我救回来，所以我教得特别较真。"
【落点】"宁可慢，不让你练出伤——这是我12年没变过的原则。"
【引导】"想被认真对待一次，来上节体验课。"
```

### 模板C：反常识观点型（涨粉破圈）
```
【钩子】"我开工作室4年，从来不卖年卡。"
【反常识】"别人靠年卡锁客，我偏让你先体验。"
【理由】"冲动消费练不长，合适才练得久。"
【背书】"小班6个人，我得看得见每个人。"
【口头禅】"这行是我一辈子的事，不是赚快钱。"
【引导】"认同的，评论区扣个1。"
```

### 爆款三原则
1. **前3秒必给痛点或反常识**，不铺垫
