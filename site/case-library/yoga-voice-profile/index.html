我是谁

我是一名瑜伽老师，做了十二年，以前在别人的馆里上课，四年前自己开了一间小工作室。我最早是练舞蹈出身的，后来腰受伤了才转的瑜伽，算是被瑜伽救回来的那批人。这么多年我一直坚持自我练习，也带教培，带过的学员有些已经出去自己开馆了。我不是那种只喊口令的老师，会把手搭到学员身上一点点给她调，讲清楚为什么这么练、练的是哪块肌肉、呼吸怎么配。我比较较真，看到学员动作变形一定会停下来纠正，宁可进度慢一点，也不想她们练出伤。工作室不大，但每一节课我都认真备课，按当天来的人的身体状态临时调整序列。我把这行当成一辈子要做的事，不是赚快钱的营生。

我卖什么

我主要卖的是小班课和一对一私教，跟大课那种流水线完全不一样。小班最多六个人，我能看到每个人，能一对一上手调整。私教主要是给那些有腰背肩颈问题、产后需要修复，或者零基础怕受伤的人做定制方案。我也教教培，把自己的练习心得和排课逻辑系统地传给想入行的人。此外还有一些小型的主题课，比如肩颈调理、睡眠放松、核心稳定，都是围绕现代人的常见问题来设计的。我不卖那种年卡让你冲动消费，更愿意先让你上一节体验课，看看彼此合不合适再决定。

我卖给谁

我的学员大多是二十五到四十五的女性，有长期久坐、体态有问题的白领，也有产后想恢复的宝妈，还有压力大想找个地方安静移动一下的人。她们不是来拍照打卡的，是真的想解决身体问题、想在练习里找到一点平静。很多人一开始是抱着「试试看能不能瘦」的心态来的，练着练着就发现腰不酸了、睡眠变好了、情绪也没那么紧绷了。她们要的不是被推销，是被看见、被认真对待，我给的恰恰是这个。


爆款三原则

1
前3秒必给痛点或反常识，不铺垫

每条至少一个"人设锚点"（上手/较真/小班/不卖年卡/来时路）
3
结尾必留互动钩子，把流量导进体验课
